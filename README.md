# AI_Research_Database
Ai Research Database 

This Project intends to establish a private user-login database for all research conducted using AI tools such as Perplexity, ChatGPT, etc.  

The project goal is to be transparent, allow users to comment on data collected, and suggest their own AI Prompts for assessment and implementation by Founding Users. 

Individual research topics are organized in their own private folder. Permissions to view the database and each folder are granted through a Substack paid or founder subscription.
